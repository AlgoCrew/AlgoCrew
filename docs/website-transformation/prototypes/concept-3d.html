Stage 4 · Visual storytelling

Four visuals, each explaining one capability.

Only the homepage hero uses real-time 3D. The other three are SVG and CSS, which cost almost nothing to load and work without JavaScript.

01 · Cloud infrastructure

Layered multi-cloud platform

Three layers: cloud foundation, platform, workloads. Signals travel between layers, and every layer carries a security outline. Move the pointer to tilt it.

Where
Homepage hero only
Technology
Plain three.js with named imports, loaded after first paint (130 KB compressed in a test build)
Fallback
The CSS stack from the homepage prototype: phones, reduced motion, no WebGL
Budget
Under 150 draw calls, pixel ratio capped at 1.75, paused off screen
